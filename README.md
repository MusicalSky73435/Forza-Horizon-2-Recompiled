# Forza Horizon 2 Recompiled
<p>A french recompilation of Forza Horizon 2 (Xbox 360) for native Linux x86</p>


<h2>Instructions</h2>

<p>1. Clone the repo</p>
<p>2. Create a folder next to play.sh named "extracted"</p>
<p>3. Extract your game in the folder you've just created with extract-xiso (AUR or build it yourself there is all the instructions on its own repo)</p>
<p>4. ./play.sh FH2</p>

<h2>Things that works</h2>
<p>Starting and playing Solo mode : Free roam, races, local events are totally functionnal</p>
<p>Xbox 360 controller is entirely operationnal : Buttons, joysticks, vibrations and triggers are working great</p>
<p>Keyboard playing, but you need to use xkey to use your keyboard as an xbox 360 controller</p>

<h2>Things that dont works (yet maybe)</h2>
<p>Online multiplayer</p>
<p>Saving photos</p>
<p>Changing username</p>

<h2>Not tested</h2>
<p>Running on integrated graphics chips</p>
<p>Applying graphics mods like GameScope or others upscalers</p>


<h2>Have fun !</h2>
